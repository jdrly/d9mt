# The AIR built-in forms contract (scripts/test-air-forms.sh, PR "AIR target per macOS").
#
# form <declared name> <fixture>... [apple-unmatched: <reason>]
#   Every intrinsic declaration AirBuilder (air/air_builder.cpp) can emit, by its declared name.
#   Each fixture must declare it: ir:<case> is air/tests/forms/gen_ir.cpp's hand-built IR through
#   `airlib_loopback --ir`; sm3:<name> is air/tests/bin/<name>.bin through the SM3 front end. The
#   declaration is compared, per target, with Apple's for the same name from forms.metal (the
#   group named in the form's `apple` column below). apple-unmatched entries (Apple's MSL can't
#   produce that exact overload) are listed in the output and reviewed by hand, never passed.
#   Half operands of the fast-math functions compute in float (callScalarMath): the math_half
#   fixture feeds them half inputs and they declare only the .f32 forms.
# site "<literal>" <form>...
#   Every "air.… literal in air_builder.cpp that names a called function, and the forms it
#   produces. A literal with neither a site nor a meta line fails the completeness check.
# meta "<literal>"
#   A literal that is metadata, a module flag or a compile option, not a function.
# LLVM's own intrinsics (llvm.fma, llvm.minnum, …) are outside this contract.
